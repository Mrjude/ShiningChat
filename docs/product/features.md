# ShiningChat - 功能特性

## 核心功能

### 1. 多轮对话
- 基于 CodeBuddy Agent SDK 的智能对话引擎
- 支持上下文关联的连续对话
- 实时流式响应，对话体验流畅

### 2. FAQ 知识库检索
- 内置 8 条预置 FAQ（退款/订单/技术支持）
- 自动根据用户问题匹配知识库答案
- 管理后台支持增删改查 FAQ 条目
- 支持关键词搜索和分类筛选

### 3. 意图识别
- 自动识别 4 类用户意图：退款、查询订单、技术支持、转人工
- 关键词匹配 + LLM 语义理解双重识别
- 意图标签实时展示在对话界面

### 4. 自动转人工
- 检测到"转人工"意图时自动标记会话
- AI 无法解决时主动引导转接人工客服
- 管理后台可查看转人工记录

### 5. 对话历史持久化
- 所有对话自动保存到 SQLite 数据库
- 会话列表展示历史记录
- 支持恢复上下文继续对话

### 6. 满意度评价
- 对话结束后弹出评价组件
- 5 星评分 + 文字反馈
- 评价数据持久化存储

### 7. 管理后台
- **数据概览**：总会话数、活跃会话、转人工数、平均评分
- **意图分布**：各意图类别的会话占比
- **每日趋势**：近 7 日会话数和评分趋势
- **对话记录**：查看所有会话的标题、意图、状态、评分
- **FAQ 管理**：新增/编辑/删除/启用/禁用 FAQ 条目

## 快捷回复
- 申请退款
- 查询订单
- 技术支持
- 转人工客服
